Plasticity: Snow and Sand

Materials that forget. One extra function after the deformation gradient update turns jelly into snow, sand and dough.

Every material in the last chapter remembered its rest shape forever. Squash a jelly block, let go, and it springs back; that memory is stored in $\mathbf F_p$ and the energy $\Psi(\mathbf F_p)$ grows the further you push it from home. Most of the materials you would actually like to simulate are not like that. A snowball packs under your hands and stays packed. A spade of sand poured on the ground slumps into a cone and then stops. A ball of dough keeps the dent of your thumb.

All three are elastoplastic: they behave elastically for small deformations and, past some limit, they accept the new shape as their new rest shape. In MPM this costs one extra function per particle, called after the $\mathbf F$ update: a return mapping that decides how much of the deformation to keep and how much to forget. The rest of the loop, P2G, grid update and G2P, is the chapter 25 loop, unchanged.

By the end of this chapter you will have written the snow model of Stomakhin et al. (SIGGRAPH 2013), which is section 6.5 of the MPM course notes, and the Drucker-Prager sand model of Klar et al. (SIGGRAPH 2016). You will know why both work on the singular values of $\mathbf F$, be able to relate a friction angle to the slope of a sand pile, and recognise the same ideas in the integration step of PB-MPM.

Forgetting part of a deformation

Roll a sausage of modelling clay and bend it into a ring. The ring is now the clay's rest shape: squeeze it gently and it pushes back toward the ring, not toward the straight sausage it used to be. The total deformation from the sausage, $\mathbf F$, has been split into a part the clay has forgotten (straight to ring) and a part it still remembers (the gentle squeeze). We write this as a product,

$$\mathbf F = \mathbf F_E\,\mathbf F_P.$$

Read it right to left: first the material is plastically deformed by $\mathbf F_P$, from its original shape to its new rest shape, then elastically by $\mathbf F_E$, from the new rest shape to where it is now. Only the elastic part stores energy, so the stress is computed from $\mathbf F_E$ alone:

$$\Psi = \Psi(\mathbf F_E), \qquad \mathbf P = \frac{\partial\Psi}{\partial\mathbf F_E}(\mathbf F_E).$$

Why a product and not a sum? Because deformations compose by multiplication, as you saw in the deformation gradient chapter: deforming by $\mathbf A$ and then by $\mathbf B$ is the deformation $\mathbf B\mathbf A$. The split says the current shape is "rest-shape change, followed by elastic stretch".

A convenient fact for MPM: we never need $\mathbf F$ itself. The velocity gradient moves the material by the same $(\mathbf I + h\nabla v)$ whatever its history, so each particle stores $\mathbf F_E$ and updates it directly. When a material needs to know something about its plastic history (snow does), a scalar summary is enough: the plastic volume change $J_P = \det\mathbf F_P$.

Trial step, then return mapping

Every material in this chapter is defined by an elastic region: the set of $\mathbf F_E$ it can hold elastically. Each step, for each particle:

  1. Trial step. Assume the whole step was elastic: $\mathbf F_E^{\text{trial}} = (\mathbf I + h\,\mathbf C_p)\,\mathbf F_E^n$ (MLS-MPM, so $\mathbf C_p$ is the velocity gradient).
  2. Return mapping. If $\mathbf F_E^{\text{trial}}$ is inside the elastic region, keep it. If not, replace it by a nearby $\mathbf F_E^{n+1}$ on the boundary of the region.
  3. Bookkeeping. The material really did move as the grid said, so $\mathbf F$ must not change. Whatever we removed from $\mathbf F_E$ moves into $\mathbf F_P$: $\mathbf F_P^{n+1} = (\mathbf F_E^{n+1})^{-1}\mathbf F^{n+1}$.

If this reminds you of position-based dynamics, it should: the trial step is the "predict" and the return mapping is a projection onto a constraint set. The difference is what gets projected. PBD projects positions, and the projection removes motion; plasticity projects $\mathbf F_E$, and the projection removes memory, which is why the material does not spring back.

Try the four materials on the snowball scene first. Jelly bounces. Snow packs into a dense chunk on impact and sprays loose powder. Sand splashes and settles. Dough squashes into a bun and stays. Then pour sand on the floor and change the friction angle; the readout measures the slope of the pile.

Work with the singular values

Every material here is isotropic: it has no preferred direction, so whether a deformation is elastic can depend only on how much the material is stretched, not in which direction or how it is rotated. That means the elastic region is a condition on the singular values of $\mathbf F_E$, its principal stretches. Write the singular value decomposition

$$\mathbf F_E = \mathbf U\,\boldsymbol\Sigma\,\mathbf V^T, \qquad \boldsymbol\Sigma = \operatorname{diag}(\sigma_0, \sigma_1),$$

with $\mathbf U$ and $\mathbf V$ rotations. A return mapping then has three steps: decompose, move the $\sigma_i$ back into the allowed region, recompose with the same $\mathbf U$ and $\mathbf V$. The rotations are never touched; plasticity only forgets stretch.

In 2D the SVD costs a handful of operations. The polar decomposition $\mathbf F = \mathbf R\mathbf S$ gives the rotation directly, as in chapter 25; the symmetric $\mathbf S = \mathbf R^T\mathbf F$ is then diagonalised by one more rotation $\mathbf V$, and $\mathbf U = \mathbf R\mathbf V$:

function svd2(F00, F01, F10, F11) {
  let c = F00 + F11, s = F10 - F01;                 // R: rotation along (F00 + F11, F10 - F01)
  const r = Math.hypot(c, s);
  if (r > 1e-12) { c /= r; s /= r; } else { c = 1; s = 0; }
  const a = c * F00 + s * F10, b = c * F01 + s * F11, d = -s * F01 + c * F11;   // S = R^T F
  const e = Math.hypot(a - d, 2 * b);               // V: tan(2 phi) = 2b / (a - d), half-angle formulas
  let cv = 1, sv = 0;
  if (e > 1e-12) { const c2 = (a - d) / e; cv = Math.sqrt(0.5 * (1 + c2)); sv = (b >= 0 ? 1 : -1) * Math.sqrt(0.5 * (1 - c2)); }
  svd.s0 = a * cv * cv + 2 * b * cv * sv + d * sv * sv;
  svd.s1 = a * sv * sv - 2 * b * cv * sv + d * cv * cv;
  svd.cv = cv; svd.sv = sv;
  svd.cu = c * cv - s * sv;  svd.su = s * cv + c * sv;   // U = R V
}

This is the "polar SVD" convention the course notes recommend: $\mathbf U$ and $\mathbf V$ are always proper rotations, and if the material is inverted ($\det\mathbf F < 0$) the sign goes into one of the singular values.

The stress is just as simple in this frame. For an isotropic energy $\Psi(\mathbf F) = \hat\Psi(\sigma_0, \sigma_1)$, the stress is $\mathbf P = \mathbf U\operatorname{diag}(\partial\hat\Psi/\partial\sigma_i)\mathbf V^T$, and the matrix MPM actually needs, $\mathbf P\mathbf F^T$, is the Kirchhoff stress $\boldsymbol\tau = J\boldsymbol\sigma$:

$$\boldsymbol\tau = \mathbf P\mathbf F^T = \mathbf U\operatorname{diag}(\tau_0, \tau_1)\,\mathbf U^T, \qquad \tau_i = \sigma_i\,\frac{\partial\hat\Psi}{\partial\sigma_i}.$$

For fixed corotated, $\hat\Psi = \mu\sum_i(\sigma_i - 1)^2 + \frac{\lambda}{2}(J-1)^2$ gives $\tau_i = 2\mu(\sigma_i - 1)\sigma_i + \lambda(J-1)J$. The code stores $\mathbf U$ and the $\sigma_i$ after each return mapping, and P2G builds $\mathbf A = V_p^0\boldsymbol\tau$ from them without another decomposition.

Snow

Snow is a loose network of ice grains. Compress it a little and it springs back; compress it more and grain contacts break and re-form, and the snow packs. Stretch it a little and it holds; stretch it more and it cracks. Stomakhin and colleagues modelled this with a deliberately simple rule on the principal stretches: the elastic region is

$$1 - \theta_c \;\le\; \sigma_i \;\le\; 1 + \theta_s, \qquad i = 0, 1,$$

with a critical compression $\theta_c$ and a critical stretch $\theta_s$, both small. The return mapping clamps each trial singular value into that interval. Everything beyond it becomes plastic, and $J_P$ records the volume that was forgotten. Since $J = J_E J_P$ must not change during the projection,

$$J_P^{n+1} = J_P^n\,\frac{J_E^{\text{trial}}}{J_E^{n+1}}.$$

A snowball pressed together has $J_P < 1$ (packed); a powdery spray that has been pulled apart has $J_P > 1$.

Clamping alone gives a material that packs without limit: throw it hard and it compacts to mush. What makes snow feel like snow is hardening: packed snow is much stiffer than fresh snow. The model scales both Lamé parameters with the plastic volume change,

$$\mu(J_P) = \mu_0\,e^{\xi(1 - J_P)}, \qquad \lambda(J_P) = \lambda_0\,e^{\xi(1-J_P)},$$

with a hardening coefficient $\xi$ between about 3 and 10. Packed snow ($J_P < 1$) stiffens exponentially, which is what eventually stops a snowball from compacting further; loosened snow ($J_P > 1$) softens, which helps it break apart.

function snowReturnMap(p) {
  const lo = 1 - thetaC.value, hi = 1 + thetaS.value;
  const s0 = Math.min(Math.max(svd.s0, lo), hi);
  const s1 = Math.min(Math.max(svd.s1, lo), hi);
  pJp[p] *= Math.abs(svd.s0 * svd.s1) / (s0 * s1);    // J_P absorbs the volume J_E lost
  svd.s0 = s0; svd.s1 = s1;
  composeF(4 * p);                                     // F_E = U diag(s0, s1) V^T
}

The demo uses the "reference" parameters of the snow paper: $\theta_c = 2.5\times10^{-2}$, $\theta_s = 7.5\times10^{-3}$, $\xi = 10$, $E_0 = 140$ kPa, $\nu = 0.2$, $\rho = 400$ kg/m³. With those, $\mu_0 = 58.3$ kPa, $\lambda_0 = 38.9$ kPa, and the wave speed of fresh snow is $c = \sqrt{(\lambda_0 + 2\mu_0)/\rho} = 19.7$ m/s.

Hardening changes the time step. The wave speed grows with the square root of the stiffness. At $J_P = 0.7$ and $\xi = 10$ the stiffness is $e^3 = 20$ times larger and $c$ is 4.5 times larger, so the explicit time step must shrink by 4.5. The demo chooses $h = 0.6\,\Delta x / c_{\max}$ every frame from the stiffest particle, which is why the readout drops from 0.46 ms to 0.11 ms the moment the snowball lands (and the demo goes into slow motion). The code also caps the exponent $\xi(1-J_P)$ at 3, the kind of safeguard the course notes recommend; without a cap, one over-packed particle can demand an arbitrarily small step.

What does the hardening do to the outcome? In our runs, one second after impact: with $\xi = 0$ the snowball is crushed to mush, with $J_P$ as low as 0.07 and three quarters of the particles packed below $J_P = 0.9$; with $\xi = 10$, $J_P$ stops at 0.50 and 38 % of the particles are packed, the rest sprayed as powder; with $\xi = 20$ only 9 % are packed. More hardening means the snow resists packing and breaks instead.

Sand

Sand has no glue. A grain resists sliding over its neighbours only through friction, and friction is proportional to how hard the grains are pressed together. So sand can carry a shear stress only in proportion to its pressure: under a heavy load it is strong, at the free surface it has no strength at all, and it cannot be pulled (there is nothing to hold the grains together in tension). The classical model of exactly this is Drucker-Prager plasticity.

Split a stress into its pressure and its shape-changing (deviatoric) part. In $d$ dimensions, with $\operatorname{dev}\boldsymbol\tau = \boldsymbol\tau - \frac1d\operatorname{tr}(\boldsymbol\tau)\mathbf I$, the Drucker-Prager elastic region is

$$\big\|\operatorname{dev}\boldsymbol\tau\big\|_F + \alpha\operatorname{tr}\boldsymbol\tau \le 0, \qquad \alpha = \sqrt{\tfrac23}\,\frac{2\sin\phi}{3 - \sin\phi},$$

where $\phi$ is the friction angle of the sand. Compression makes $\operatorname{tr}\boldsymbol\tau$ negative, so the allowed shear grows with the pressure. In principal stress space this region is a cone around the "hydrostatic" axis, with its tip at zero stress, which is why the return mapping talks about projecting onto the cone or to its tip.

Klar and colleagues made this cheap by choosing an elastic law that is linear in the Hencky (logarithmic) strain $\boldsymbol\epsilon = \log\boldsymbol\Sigma$, that is $\epsilon_i = \log\sigma_i$:

$$\hat\Psi = \mu\sum_i \epsilon_i^2 + \frac{\lambda}{2}\Big(\sum_i\epsilon_i\Big)^2 \quad\Longrightarrow\quad \tau_i = 2\mu\,\epsilon_i + \lambda\operatorname{tr}\boldsymbol\epsilon.$$

Now stress and strain are proportional in the principal frame, and the cone in stress becomes a cone in strain: $\|\hat{\boldsymbol\epsilon}\| \le -\frac{d\lambda + 2\mu}{2\mu}\,\alpha\operatorname{tr}\boldsymbol\epsilon$, with $\hat{\boldsymbol\epsilon}$ the deviatoric strain. The return mapping has three cases:

  1. Expansion, $\operatorname{tr}\boldsymbol\epsilon \ge 0$: the grains are being pulled apart and carry no stress at all. Project to the tip of the cone: $\boldsymbol\Sigma = \mathbf I$, so $\mathbf F_E = \mathbf U\mathbf V^T$, a pure rotation.
  2. Inside the cone: compute $\delta\gamma = \|\hat{\boldsymbol\epsilon}\| + \frac{d\lambda + 2\mu}{2\mu}\,\alpha\operatorname{tr}\boldsymbol\epsilon$. If $\delta\gamma \le 0$, the shear is small enough for the pressure; keep the strain.
  3. Outside the cone, $\delta\gamma > 0$: too much shear. Remove $\delta\gamma$ along the deviatoric direction, $\boldsymbol\epsilon \leftarrow \boldsymbol\epsilon - \delta\gamma\,\hat{\boldsymbol\epsilon} / \|\hat{\boldsymbol\epsilon}\|$, which lands exactly on the cone, and set $\boldsymbol\Sigma = \exp(\boldsymbol\epsilon)$.

Case 3 keeps the pressure and reduces only the shear: the sand slides, and the slide is the plastic flow.

Volume correction. Case 1 has a side effect. Every time an expanding particle is projected to the tip, the expansion is forgotten, so sand that dilates and is then squeezed back starts resisting compression too early, and piles slowly gain volume. Klar et al. fix this by remembering the forgotten expansion as a scalar, the log of the volume gained; our code calls it pLogJp. It is added to the strain before the case analysis ($\epsilon_i \mathrel{+}= \frac12$pLogJp in 2D), so dilated sand must first be compressed back before it feels any stress. In case 1 the new value is the current corrected trace; in cases 2 and 3 the gap has closed and it returns to zero.

const e0 = Math.log(Math.abs(svd.s0)) + 0.5 * pLogJp[p];
const e1 = Math.log(Math.abs(svd.s1)) + 0.5 * pLogJp[p];
const tr = e0 + e1;
if (tr >= 0) { pLogJp[p] = tr; svd.s0 = 1; svd.s1 = 1; }            // case 1: tip
else {
  pLogJp[p] = 0;
  const h0 = e0 - 0.5 * tr, h1 = e1 - 0.5 * tr, hn = Math.hypot(h0, h1);
  const dGamma = hn + (2 * M.la + 2 * M.mu) / (2 * M.mu) * tr * alpha;
  if (dGamma <= 0) { svd.s0 = Math.exp(e0); svd.s1 = Math.exp(e1); }   // case 2: inside
  else { svd.s0 = Math.exp(e0 - dGamma * h0 / hn); svd.s1 = Math.exp(e1 - dGamma * h1 / hn); }  // case 3
}
composeF(4 * p);

The demo uses the sand of the Drucker-Prager paper, $E = 353.7$ kPa, $\nu = 0.3$, $\rho = 2200$ kg/m³, so $c = 14.7$ m/s and the adaptive step is about 0.62 ms. Klar et al. also let the friction angle grow as sand is sheared (a hardening of $\phi$); we keep $\phi$ fixed, as the PB-MPM code does.

The angle of repose

Pour sand on a table and it forms a cone whose sides make a fixed angle with the table, the angle of repose. For a cohesionless Mohr-Coulomb material the textbook result is that an infinite slope is stable as long as its angle is below the friction angle: on the slope, the weight of a layer pushes it down the slope with $\rho g d\sin\theta$ and into the slope with $\rho g d\cos\theta$, and friction can hold it while $\tan\theta \le \tan\phi$. So the first prediction is simply repose angle $\approx \phi$.

Our 2D cone needs one correction. The constant $\alpha$ above is matched to Mohr-Coulomb in 3D. In 2D, with only two principal stresses, the cone $\|\operatorname{dev}\boldsymbol\tau\| \le -\alpha\operatorname{tr}\boldsymbol\tau$ reads $\frac12|\tau_0 - \tau_1| \le \sqrt2\,\alpha\,p$, with $p = -\frac12(\tau_0 + \tau_1)$ the pressure. Mohr-Coulomb in 2D reads $\frac12|\tau_0 - \tau_1| \le \sin\phi\;p$, so our sand behaves like Mohr-Coulomb with

$$\sin\phi_{2D} = \sqrt2\,\alpha.$$

We checked the model two ways. A static heap built with 28° sides holds at $\phi = 40^\circ$ and $50^\circ$, and slumps at $\phi = 30^\circ$ (to 24°) and $20^\circ$ (to 11°), as $\phi_{2D}$ predicts. Pouring, the measured slopes come out a few degrees lower:

The ranges come from runs with slightly different time steps: a pile's measured slope wobbles by a few degrees from run to run, so do not read too much into a single number.

The trend is right, but why lower? A poured pile is built by avalanches: grains arrive with speed, the surface flows, and a flowing slope overshoots the static angle before it stops (the static heap at $\phi = 20^\circ$ did the same, slumping well below 17°). The top cell or two of particles is also poorly resolved: a B-spline spreads the surface over about one cell, so near the surface the pressure, and with it the friction, is underestimated. Real sand adds a further twist that this continuum model lacks, a difference between the angle at which a slope starts to slide and the one at which it stops. Treat "repose angle $\approx \phi$" as the first estimate it is, and measure.

Drucker-Prager sand in the papers

The sand model is from Drucker-Prager Elastoplasticity for Sand Animation (Klar, Gast, Pradhana, Fu, Schroeder, Jiang, Teran, SIGGRAPH 2016). The MPM course notes cite it at the end of section 6.5 as the more rigorous treatment that respects thermodynamics and keeps plastic flow volume-preserving where it should. The PB-MPM code implements the same three cases in its integration step (particleIntegrate.wgsl), with a few simplifications worth recognising when you read it: the factor $\frac{d\lambda + 2\mu}{2\mu}$ is written with a user-controlled "elasticity ratio" standing in for $\lambda/\mu$ (in 2D, $\frac{2\lambda + 2\mu}{2\mu} = \lambda/\mu + 1$); the stored dilation is multiplied by $\beta = \frac12$ every time it is updated, so it fades instead of being kept in full; and inside the cone the stored dilation is simply dropped.

Dough: forget shape, keep volume

Bread dough, clay and thick pastes flow when pushed hard enough and hold their shape otherwise, but unlike snow they do not pack: their volume barely changes. A simple model that captures both: clamp the singular values to a band $[1/(1+y),\ 1+y]$ around 1, with a yield stretch $y$, exactly as for snow, and then rescale them so that the determinant is what it was before the clamp:

$$\sigma_i \leftarrow \operatorname{clamp}\!\Big(\sigma_i, \tfrac{1}{1+y}, 1+y\Big)\;\sqrt{\frac{J^{\text{trial}}} {\prod_j \operatorname{clamp}(\sigma_j)}} .$$

(In 2D, scaling both singular values by $s$ scales the determinant by $s^2$, hence the square root.) Shape change beyond the yield stretch is forgotten, so the dough flows; volume change is never forgotten, so the dough keeps resisting compression elastically and never packs. The yield stretch sets the yield stress: with the demo's $\mu$ = 23 kPa and $y = 0.12$, shear stresses of roughly $2\mu y \approx$ 5.5 kPa are needed to make it flow, so a 22 cm blob dropped on the floor squashes into a bun about half as tall and stops. Lower $y$ and it spreads into a pancake.

Strictly, this is a rate-independent plastic flow: the dough flows at any speed once it yields. Real visco-plastic models also make the flow rate depend on how far the stress exceeds the yield stress, which makes very slow flows like honey-thick pastes possible; the course notes point to MPM papers on foams and complex fluids for that (Yue et al. 2015, Ram et al. 2015).

how PB-MPM integrates sand and visco-plastic material

In the PB-MPM code, all plasticity lives in the final integration step, after the position-based iterations (you will build that loop in the PB-MPM chapter). For every non-liquid particle it first updates $\mathbf F \leftarrow (\mathbf I + \mathbf D)\mathbf F$ with the converged deformation displacement, takes the SVD, and clamps the singular values to $[0.2, 10^4]$ as a safety net. Then:

  • Sand runs the Drucker-Prager return mapping above, in log strain, with the friction angle from the UI and the simplifications noted in the previous box.
  • Visco is our dough: the yield band is $[1/s, s]$ with $s = e^{1 - \text{plasticity}}$, followed by the same volume-restoring rescale by $\sqrt{J/J_{\text{new}}}$.

The constraint solve inside the iterations also treats sand specially: when a particle has no stored dilation, the target shape it is pulled toward has its singular values clamped to at least 1, so it resists compression but not stretching. That is the position-based reading of "sand cannot be pulled".

Summary

  • Elastoplastic materials split the deformation as $\mathbf F = \mathbf F_E\mathbf F_P$. Only $\mathbf F_E$ stores energy; $\mathbf F_P$ is the forgotten part, the change of rest shape. MPM particles store $\mathbf F_E$ (and, when needed, a scalar like $J_P$).
  • Each step: a trial elastic update $\mathbf F_E \leftarrow (\mathbf I + h\mathbf C_p)\mathbf F_E$, then a return mapping back into the elastic region. For isotropic materials both are done on the singular values, keeping $\mathbf U$ and $\mathbf V$.
  • Snow clamps the singular values to $[1-\theta_c, 1+\theta_s]$ and hardens with $e^{\xi(1-J_P)}$. Hardening raises the wave speed, so the explicit step must shrink with it.
  • Sand is Drucker-Prager in Hencky strain: expansion goes to the tip (no stress), excess shear is projected onto the cone, and a volume correction remembers dilation. The friction angle sets the slope of a pile, roughly.
  • Dough clamps the singular values and restores the volume, so it flows without packing.
